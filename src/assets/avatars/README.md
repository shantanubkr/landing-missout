# MissOut procedural avatars

Avatar geometry and animations are authored with
[Bible Strong Avatar Lab](https://github.com/smontlouis/bible-strong-avatar-lab) and rendered via
`@bible-strong/avatar-react`.

- `backstage-guide.avatar.json` — primary Backstage marketing guide (brand blue)
- `contact-host.avatar.json` — demo / contact flows
- `stage-student.avatar.json` — Stage-facing surfaces (ink body, blue eyes)
- `MissoutStarAvatar` uses `public/brand/missout_star.svg` (set `avatar="star"`)

the `.avatar.json` files.
