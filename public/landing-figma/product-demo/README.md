# Home product demo (`/landing-figma/product-demo/`)

Screenshots (or videos) for the **Make event / Check-In / …** tabs on the landing home.

| File | Tab |
|------|-----|
| `make-event.png` | Make event |
| `check-in.png` | Check-In |
| `registrations.png` | Registerations |
| `contingents.png` | Contingents |
| `payments.png` | Payments |

**Videos:** edit `src/lib/landingProductDemo.ts` and set `kind: 'video'` with `src: '/landing-figma/product-demo/your-clip.mp4'` (optional `poster`).

Paths are wired in **`src/lib/landingProductDemo.ts`**.
