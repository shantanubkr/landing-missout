# MissOut pixel icons

Source SVGs shared with **missout-v2** (`icons/`). Generated registry: `src/components/icons/paths.ts`.

```bash
npm run generate-icons
```

Usage:

```tsx
import { MissoutIcon } from '@/components/icons'

<MissoutIcon name="calender" size={18} className="text-[var(--fu-brand-blue)]" />
```

Marketing icon maps live in `src/lib/marketingIcons.ts`.
